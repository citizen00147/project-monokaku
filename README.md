# project-monokaku

A terminal-like typewriter. The interface runs entirely in the web browser on localhost, combining vintage form with digital flexibility. There’s no internet access, no pop-ups, no cloud sync — just you, your words, and a responsive interface that feels like a stripped-down terminal or early GUI.

### Current Features:

- 🖥️ Local-only web UI with keyboard-first interaction
- 💾 Save to local storage or disk — no external dependencies
- 🌐 Accessible on http://localhost — no login, no nonsense

### The Hardware:

- 🔋 Built to last — low-power Raspberry Pi Zero (for localhost server and UI) and Raspberry Pi Pico (for handling keyboard matrix)
